# 长度与分段专家：实现与真实 API 验证

2026-10-21，分支 `feature/stage-two-grid-agents`。专家已接入生产第二阶段，和网格 children、master、格式重试共享同一个就绪队列和请求池。第一阶段、第三阶段去重算法保持不变。

## 职责与边界

- 目标为 UNKNOWN、分段 UNRESOLVED 和所有 DIAGONAL；非目标记录不改。
- 首轮只传构件身份、规格、所属面、标签位置、原图与高清网格。刻意不传旧长度、旧直角边、旧端点和旧位置结论，避免沿用上游错误。
- 专家返回原始尺寸/标高引用、共享拼接依据、两个端点和 DIRECT 或 HORIZONTAL/VERTICAL 表达式；本地完成引用检查、表达式计算及勾股，两位小数。
- OF SPLICE 和标尺只标一处时，要判断远处构件是否共用对应拼接基准，保留具体对应理由，不能靠同规格或图案印象推定。
- 每视图一轮，只有明确补图请求或本地引用/结构错误才追加一轮；最多一张合并上下文裁图。请求格式失败单独重试最多两次。失败与未解决项保留原结果，不阻断整份台账。
- 专家不增删构件、不改规格、数量、view_tags 或来源身份。需重新分段时标记 CONFLICT 并说明，本版不自动改变拓扑。
- 比例标定按视图和方向建立，至少两个不同跨度/位置，系数差异不超过 2% 才生成辅助测量。比例估算不写入确定 `length_mm`，不参与去重。它仅检验模型引用的坐标与标注的一致性，不证明点位、标注或工程对应正确。
- `length_review` 保留修改前记录、实际专家回复、引用、表达式与本地检查；网页可展开，后续正常导出包含 `Length Expert Audit`。

## 首轮试验发现

任务 `59c7879091c2459c9b99d4c04cc4f82c` 最初向专家提供旧端点、位置、长度与直角边。专家沿用“半高节点”结论，12 条错误斜撑仍为 3605.55 mm。该试验还因一个旧无效网格响应重新请求 children/master，使新旧构件身份顺序发生变化，未通过冻结身份检查。

据此修正了输入隔离，并新增显式冻结真实 master 的实验入口。它按图片指纹校验已保存真实 master 和局部观察，只复用其输出，真实调用专家；不构造模拟模型回答，不靠修订原响应修复缓存。
