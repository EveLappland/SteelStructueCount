## 并发与持久化

- 新流程任务串行；第一阶段文件 task 默认 10，单文件逐页。
- 所有一阶段交付后再二阶段；各文件协调器共享 `TaskSlots(10)`，每视图独立 `ViewRequests(5)`。网格、主、专家、仲裁和重试占用该视图额度，不是全局 5。
- 所有二阶段交付后再三阶段；匹配组 task 默认 10，另有默认 24 次请求预算。
- PDF 原生提取与渲染加锁，API 等待在锁外。各文件输出独立；协调器排序保存 `current_outputs` 等状态，失败不丢其他已完成文件。
- 新状态库 `data/native_runs.sqlite3`，产物 `data/native_runs/`；旧状态库 `data/jobs_v2.sqlite3`、`data/jobs/`。两者在原页面统一展示。
- 重启只标记中断，不自动恢复付费请求。显式重试校验来源/请求签名；已完成后二阶段重跑保留一阶段，后续结果失效，历史不删除。
