# PDF 标签着色实验

第一阶段在保留原始 300 DPI 裁图的同时，生成同尺寸的文字着色图与审计 JSON。紫色表示 PDF 原生文字中识别出的钢材规格，蓝色表示轴线/标高名称。匹配基于文字对象与每个字符的位置，因此支持斜排文字；没有从位图推断尺寸或构件位置。图纸中的其他内容不主动着色。

第二阶段以 `label_color_mode=colored` 选择彩色图及其同样着色的局部放大图；缺省继续使用原图，便于对照。原图与彩色图使用相同提示词和输出契约。

用已有任务的单页两个立面生成原图/着色图并查看审计：

```powershell
python tools/experiment_label_colors.py --job <任务ID> --page <页面ID>
```

加 `--api` 会各做一次原图与着色图的付费首轮识别，保存模型原始响应、用时和台账对照到 `tmp/label_color_experiment/`。实验脚本不会修改源任务。

局限：这种方法对字符包围盒内的深色像素着色；如果图线恰好穿过字形，交叉处可能有少量线像素同色。扫描 PDF 和不可提取文字不适用。着色提高可见性，不构成钢材数量或长度正确性的证明。
