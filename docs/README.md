## 保留与清理边界

[完整 key 去重](exact-key-dedup.md) 仍用于旧 `/api/jobs`，随兼容接口保留。旧任务的查看、编辑、重试及相关回归测试也保留。

已移除过时的独立服务、着色 A/B 与长度专家实验驱动，以及旧网格、专家、经济模式、着色和早期重构报告。历史过程可查 Git；当前运行说明只维护上述文档。独立离线评分、产物核验与旧接口回归工具仍保留，不能用旧接口测试代表新网页验收。

验收 PDF、人工参考表、模型原始回复和任务输出属于本地数据，不随仓库发布。文档示例中的路径和 ID 应换成自己的实际输出，不包含测试答案。
